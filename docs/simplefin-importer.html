SimpleFin Importer

Synchronize transactions directly and securely from your financial institutions into PPBudget with automated account mapping and background scheduling.

What is SimpleFin?

SimpleFin Bridge is a lightweight, privacy-focused financial aggregation service designed to securely connect your bank, credit union, and credit card accounts to personal finance applications like PPBudget.

🔒

Read-Only Security

SimpleFin only provides read-only transaction and balance data. It has zero capability to transfer money, initiate payments, or alter account states.

⚡

Automated Syncing

Eliminate tedious CSV exports and manual balance entries. Your actual cleared transactions flow directly into your budgeting dashboard.

🛡️

Privacy First

Your banking login credentials stay securely within SimpleFin's isolated infrastructure. PPBudget only communicates with an encrypted, unique access token.

Setting Up the SimpleFin Connection

Connecting your financial accounts to PPBudget takes just a couple of minutes using SimpleFin's secure claim process.

1

Create Your SimpleFin Account

Sign up or log in to your account at SimpleFin Bridge (beta.simplefin.org).

2

Link Your Banks

In your SimpleFin dashboard, add and authenticate the banks, credit cards, or investment accounts you wish to track in PPBudget.

3

Generate a Setup Token (Claim URL)

Create a new connection token in SimpleFin. SimpleFin will generate a Setup Token / Claim URL (either a base64 encoded string or a direct secure claim URL starting with https://...).

4

Connect in PPBudget Settings

In PPBudget, open Settings → Data Importer (/settings/importer). Paste your setup token into the Setup Token input field and click Continue.

Behind the Scenes: Claim Exchange

When you click Continue, PPBudget sends a secure POST request to the SimpleFin Claim URL. SimpleFin responds with an encrypted, persistent Access URL containing your user credentials. PPBudget securely stores this access token inside your user profile settings in the database for all future synchronization pulls.

Account Mapping & Account Memory

Once connected, PPBudget queries SimpleFin for all active accounts under your bank connections and presents the interactive Account Mapping Wizard.

How Mapping Works

For each account discovered in SimpleFin, you can specify how PPBudget handles incoming data:

  • Map to Existing Account: Associate the SimpleFin account with an account you already created in PPBudget (e.g., "Chase Freedom", "Ally Savings").
  • + Create New Account: Automatically create a matching account in PPBudget with the current balance and currency fetched from SimpleFin.
  • Skip Importing: Ignore this account entirely during import operations.
Core Architecture

Persistent Account Memory

PPBudget features an intelligent Account Memory system. When you configure your account mappings:

  1. The system creates an associative map between each external SimpleFin Account ID (e.g., ACT-89421-XYZ) and the target PPBudget Account ID (UUID).
  2. This mapping is stored securely in the database inside user_settings under the simplefin_config key, alongside your access credentials.
  3. Additionally, the foreign key relationship is recorded directly in your PPBudget accounts table (via simplefin_account_id).

The Result: On every subsequent manual pull and background automatic sync, PPBudget automatically routes each transaction to its designated target account without requiring any re-configuration.

Import Configuration Options

Before running an import, you can tailor how transactions are ingested and processed:

Option Default Description
Import Start Date 30 days ago Specifies the historical cutoff date. Transactions posted before this date will be skipped.
Import Pending Transactions Disabled When enabled, imports unsettled transactions. Note that pending amounts and merchant descriptions may change once cleared by the bank.
Apply Categorization Rules Enabled Automatically executes active Rules Engine rules on newly ingested transactions to assign categories, tags, and subscriptions immediately.
Smart De-duplication Enabled Uses content hashing (date, exact integer amount, and cleaned description) plus SimpleFin's unique transaction IDs to guarantee no duplicate records are created.

Automated Background Sync (12-Hour Cron)

PPBudget is built for hands-off automation. You don't need to manually click sync buttons every day to keep your budget current.

Scheduled Background Execution

PPBudget runs a built-in background scheduler that executes every 12 hours (@every 12h). For all users with Auto-Sync enabled:

  • The engine pulls the last 30 days of transactions from SimpleFin.
  • It uses your saved Account Memory configuration to map transactions to the right accounts.
  • It applies smart de-duplication to skip already-imported records.
  • It executes active Categorization Rules to organize the new transactions.

Enabling Auto-Sync

To enable automated syncing:

  1. Go to Settings → Data Importer (/settings/importer).
  2. Toggle the Auto-Sync switch on the dashboard card.
  3. The interface displays the next scheduled sync time (e.g., Next: Sep 1, 11:30 AM).

Email Notifications

Whenever a background auto-sync completes with new transactions, PPBudget sends a detailed HTML email summary directly to your notification address. The email includes:

  • Total number of newly imported transactions.
  • Counts of automatically categorized items vs. items requiring manual review.
  • A formatted transaction ledger grouped by account, complete with direct links to review or edit transactions.

Manual On-Demand Sync

If you made a recent purchase and want to see it reflected immediately, you can trigger a manual sync anytime:

  1. Navigate to Settings → Data Importer.
  2. Click the Sync Now button.
  3. Review the discovered accounts and click Continue through the wizard.
  4. Click Start Import to watch the live progress bar import and categorize your transactions in real-time.
