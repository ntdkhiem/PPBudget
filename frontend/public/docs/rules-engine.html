Automation & Workflow

Rules Engine

Automate transaction categorization, subscription tracking, and budget tagging with flexible, condition-based rule triggers.

What is the Rules Engine?

The Rules Engine in PPBudget is an automated transaction processing system. Rather than manually assigning categories and tags to dozens of bank transactions every week, you can configure declarative If → Then rules.

Whenever transactions are imported from SimpleFin, uploaded via CSV, or created manually, active rules automatically inspect the transaction properties and apply the designated category, subscription link, or tag instantly.

Anatomy of a Rule

Every rule in PPBudget is composed of three primary parts:

1. Triggers (If)

One or more conditions evaluated against the transaction (e.g., Description contains "Starbucks").

→
2. Match Logic

Match All (AND) or Match Any (OR).

→
3. Actions (Then)

One or more operations performed when matched (e.g., Set Category to "Coffee").

1. Trigger Fields & Operators

Rules can match on multiple attributes of a transaction:

Field Supported Operators Example
Description contains, is exactly, starts with, ends with Description contains "Starbucks" or starts with "UBER *"
Amount greater than, less than, is exactly Amount greater than "100.00" (e.g. flagging large expenses)
Account is exactly Account is "Business Checking"

2. Match Logic (Strictness)

  • Match All (AND): Every condition defined in the rule must evaluate to true for the action to trigger.
  • Match Any (OR): If any single condition in the list is met, the rule will execute its actions.

3. Available Actions

When a transaction meets the conditions, the Rules Engine can perform any of the following actions:

  • Set Category: Assigns the transaction to a specific category (e.g., Groceries, Dining Out, Utilities).
  • Link to Subscription: Connects recurring transactions (such as Netflix or Spotify) directly to a tracked subscription profile.
  • Add Tag: Attaches custom labels (e.g., #tax-deductible, #reimbursable, #vacation) for granular filtering.
  • Set Budget: Allocates the transaction toward a particular budget envelope.
  • Link as Card Payment: Flags internal transfer entries as credit card payoff transactions.

How to Create a Rule (Step-by-Step)

Let's walk through an example of creating a rule that automatically categorizes all Starbucks purchases as "Coffee & Drinks".

1

Navigate to Rules Settings

Open Settings → Rules (/settings/rules) in your PPBudget navigation.

2

Click "Create Rule"

Click the + Create Rule button at the top right of the page to open the Rule Builder dialog.

3

Name Your Rule

Enter a descriptive name such as Coffee - Starbucks and an optional description.

4

Define Triggers (If)

Configure the matching condition:

  • Field: Description
  • Operator: Contains
  • Value: Starbucks
5

Define Actions (Then)

Configure what PPBudget should do when a match is found:

  • Action: Set Category
  • Value: Select Coffee & Drinks (or your preferred category) from the dropdown list.
6

Save & Activate

Click Save Rule. The rule is immediately active for all future transaction imports.

Applying Rules to Existing Transactions

When you create or update a rule, you often want it to categorize transactions that were already imported in the past. PPBudget provides built-in retroactive execution:

Retroactive Processing

Run Rule on Existing Transactions

When creating or editing a rule, enable the checkbox "Run rule on existing transactions":

  • All Past Transactions: Scans your entire historical transaction database and updates every matching transaction.
  • Specific Date Range: Choose a Start Date and End Date to limit retroactive categorization to a specific timeframe (e.g. the current month).

Upon saving, PPBudget immediately processes the transactions in the background and reports how many historical transactions were updated.

Automatic Integration with SimpleFin

The Rules Engine works hand-in-hand with the SimpleFin Importer:

  1. Every 12 hours (or on manual sync), SimpleFin fetches cleared transactions from your banks.
  2. When Apply Categorization Rules is enabled, PPBudget immediately feeds each newly ingested transaction through your active rules pipeline.
  3. Transactions matching your rules are categorized automatically before you even open the app.
  4. Your budget progress bars, category breakdowns, and dashboard analytics update in real time.

Best Practices for Writing Rules

💡 Use Broad Substrings for Merchants

Bank statements often append store numbers or location codes (e.g. STARBUCKS #10482 SEATTLE WA). Using Description contains "Starbucks" will reliably match all store locations.

💡 Combine with Amount for Multi-Purpose Merchants

For retailers like Amazon or Target, combine Description contains "Amazon" with Amount less than "25.00" to separate small digital purchases from large household orders.
